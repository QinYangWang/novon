novon は MDX のフォルダーをドキュメントサイトやブログに変えます。サイトは設定ファイル
1 つと `content/` だけ。`package.json` もビルドスクリプトも、保守するテーマも要りません。

```bash
bun add -g novon
novon new my-docs
cd my-docs && novon dev
```

## 名前について

`novon` は猫 ฅ^•ﻌ•^ฅ を文字で書いたものです。2 本の前足、2 つの目、そして鼻。
小文字でしか成り立たないので、名前はいつも `novon` です。
