## Feature parity, part 2 (2026-11-06)

- More than one language: `i18n`, translated sidebars, hreflang, per-language search, feeds and sitemaps.
- Frozen docs versions with `novon version`, a version switcher and archived versions.
- Content from other repositories, URLs and GitHub releases, cached by `novon sync`.
- API reference pages from OpenAPI descriptions.
- `novon add`, `novon audit`, changelog pages and page feedback.

## Feature parity, part 1 (2026-11-06)

- Agent files: page JSON, skills, discovery documents and in-browser tools.
- Section search, `_meta` files, partials and variables.
- Math, diagrams, type tables, diffs, prompts, image zoom and a site banner.
- Analytics, print styles, plugin hooks and size budgets.

## Feature parity, part 0 (2026-11-06)

- `llms-full.txt`, `novon check`, code notations, package install tabs and callouts.
- Redirects, structured data, page actions and Markdown output for every page.
