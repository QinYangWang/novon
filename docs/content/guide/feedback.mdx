---
title: Feedback
description: Ask readers whether a page helped, and send the answer where you want.
icon: MessageSquare
---

```ts title="novon.config.ts"
export default defineConfig({
  feedback: {
    href: 'https://github.com/acme/docs/issues/new?title=Feedback: {title}&body={message}%0A%0A{url}',
  },
})
```

Docs pages end with "Was this page helpful?". novon runs no server, so
the answer goes where you say:

<TypeTable>
  <Field name="href" type="string">A URL opened in a new tab with `{page}`, `{url}`, `{title}`, `{mood}` and `{message}` filled in, or `post:` + a URL to send JSON there.</Field>
  <Field name="event" type="string | false" default="'feedback'">Analytics event sent with the page and mood to every configured provider that takes events.</Field>
  <Field name="on" type="'docs' | 'blog' | 'all'" default="'docs'">Where the widget shows.</Field>
</TypeTable>

Turn it off for one page with `feedback: false` in its frontmatter.
