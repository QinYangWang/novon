`layout` picks the layout for the whole site. `layers` mounts another layout
under a URL prefix; the longest prefix wins.

```ts title="novon.config.ts"
export default defineConfig({
  title: 'Acme',
  layout: 'docs',
  layers: [{ path: '/blog', layout: 'blog', title: 'Blog' }],
  nav: [
    { label: 'Docs', href: '/guide' },
    { label: 'Blog', href: '/blog' },
  ],
})
```

## Docs

A sidebar built from `content/`, search, page actions (copy as Markdown, view
raw, edit), "On this page" and previous/next cards. A folder's `index.mdx`
heads its section; nested folders fold under their index page.

## Blog

The layer root lists posts: the newest as a featured card, then the rest.
Pages with a `date` are posts; each tag gets a page at `<layer>/tags/<tag>`.
An `index.mdx` at the layer root replaces the list; put `<PostList />` in it to
keep the posts. Pages without a date, like an About page, render as plain pages.

A post can set `cover` (an image under `public/`) and `author`. Without a
cover, the post gets generated cover art in the site's accent; `cover: false`
leaves it out. When `author` matches a name in `theme.authors`, the post ends
with that author's card.

```mdx
---
title: Plain text
date: 2026-10-02
tags: [writing]
author: Ada Park
cover: /covers/plain-text.svg
---
```

See both on the [Templates](/templates) page.
