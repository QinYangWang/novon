`novon new` copies a template into a new folder. Both demos below are the
templates as scaffolded, with no changes.

<TemplateCard name="docs" title="Docs">
  For product and project documentation.
</TemplateCard>

```bash
novon new my-docs
cd my-docs
novon dev
```

<TemplateCard name="blog" title="Blog">
  For a personal site or a team's writing.
</TemplateCard>

```bash
novon new my-blog --template blog
cd my-blog
novon dev
```

## Mix them

A docs site can mount a blog under a path, and the other way round. See
[Layouts](/guide/layouts).
