  lang: 'en',                     // built-in strings and dates; see Language
  trailingSlash: false,           // write guide.html instead of guide/index.html
  layout: 'docs',                 // 'docs' | 'blog'
  layers: [],                     // see Layouts
  nav: [{ label: 'Guide', href: '/guide' }],
  theme: {
    accent: 'blue',               // blue, neutral, green, orange, rose, violet
    radius: '0.75rem',
    toc: true,

    logoDark: '/logo-dark.svg',
    favicon: '/favicon.svg',
    social: { github: 'https://github.com/acme', email: 'hi@acme.dev' },

    footer: { text: '© Acme', links: [{ label: 'Privacy', href: '/privacy' }] },
    authors: { 'Ada Park': { bio: 'Writes the changelog.', avatar: '/ada.jpg' } },

    pageActions: ['copy', 'markdown', 'pdf', 'edit', 'chatgpt', 'claude', 'perplexity'],

  og: { font: './fonts/NotoSansSC-Bold.ttf' }, // see Share images; false turns them off

## Language

`lang` sets `<html lang>`, date formats and the words the layouts print.
English and Simplified Chinese ship built in; any `zh` tag uses Chinese, other
languages use English. Replace single strings with `theme.labels`:

```ts
lang: 'zh-CN',
theme: { labels: { onThisPage: '目录', minRead: '约 {n} 分钟' } },
```

`{n}`, `{date}` and `{novon}` are filled in. The keys are the `Labels` type
exported from `novon`, for example `onThisPage`, `keepReading`, `latest`,
`allWriting`, `topics`, `allPosts`, `previous`, `next`, `updated`, `minRead`,
`postCount`, `noPosts`, `copyPage`, `editPage`, `search` and `notFoundTitle`.

## URLs

Links, canonical URLs, the sitemap and feeds never end in a slash. Pages are
written as `guide/index.html` by default; `trailingSlash: false` writes
`guide.html`, for hosts that would otherwise redirect `/guide` to `/guide/`.

Tag pages of a blog layer live under `tags.path` (`/tags/<tag>` by default).
`lowercase: false` keeps the tag's case, so `Docker` stays `/tag/Docker`.

The `rss` plugin writes `rss.path`. A path with no extension, like `/feed`,
is written as is; `full: true` adds each post's HTML to its item.

## Share images

Every page gets a 1200×630 card at `/og/<route>.png` with its title, the site
name and logo, and on posts the author, date and first three tags, plus the `og:image` and
`twitter:*` tags that point at it. Set `url` so the image link is absolute.

```ts
og: {
  enabled: true,               // or og: false
  font: './fonts/Sans.ttf',    // local TTF, OTF or WOFF; or ['./Regular.ttf', './Bold.ttf']
  family: 'Noto Sans SC',      // web font when font is unset; follows lang by default
  mode: 'light',               // 'light' | 'dark'
  accent: 'blue',              // defaults to theme.accent
}
```

Without `font`, each card downloads a subset of the web font holding only its
own characters, so CJK titles render without a large font file. Builds without
network need `font`, which must cover `#`, `·` and `…`; if neither works, pages ship without a card. Cards and
font subsets are cached in `.novon/og/`, so unchanged pages are not redrawn.
A page can use its own image or opt out in [frontmatter](/guide/content#frontmatter).

## Redirects

```ts
redirects: {
  '/start': '/getting-started',
  '/chat': 'https://discord.gg/acme',
},
```

A page can list its old paths with frontmatter `redirectFrom`. The build writes
`_redirects` for hosts that read it (rules already in `public/_redirects` are
kept) and a small page at each old path that forwards the browser, so hosts
without redirect rules work too. `novon dev` and `novon preview` follow them.

## Page actions

The menu beside "Copy page" on docs pages. List the actions in order; `false`
hides the menu.

```ts
theme: {
  pageActions: [
    'copy',          // copy the page as Markdown
    'markdown',      // open <page>.md
    'pdf',           // print, or save as PDF
    'edit',          // needs theme.editLink
    'chatgpt', 'claude', 'perplexity',
    { label: 'Ask Acme AI', href: 'https://ai.acme.dev/?q={prompt}' },
  ],
},
```

In `href`, `{prompt}` is "Read … and answer questions about it" with the
page's Markdown URL, `{markdown}` that URL and `{url}` the page itself. Blog
posts show the menu only when `pageActions` is set.

"Download PDF" opens the print dialog. The print stylesheet keeps only the
page's content: no header, sidebars, outline or banner, code blocks unclipped,
and blocks kept whole across pages.

## Banner

A line above the header of every page, for an announcement. Inline Markdown
works: `**bold**`, `` `code` ``, `[links](/x)`.

```ts
banner: {
  text: 'Version 2 is out. [Read what changed](/blog/v2)',
  href: '/blog/v2',     // make the whole banner a link
  dismissible: true,    // default; a closed banner stays closed
  id: 'v2',             // change it to show a closed banner again
},
```

A string is the same as `{ text }`. Without `id`, changing the text shows the
banner again to readers who closed it.

## Analytics

```ts
analytics: {
  plausible: { domain: 'acme.dev' },         // src for a self-hosted script
  umami: { websiteId: '…', src: 'https://umami.acme.dev/script.js' },
  ga4: 'G-XXXXXXX',
  cloudflare: 'token',                       // Cloudflare Web Analytics
  custom: 'https://stats.acme.dev/script.js', // or head elements
},
```

Each adds its script to every page. Moving between pages without a reload
counts as a page view: the scripts follow the browser history.

## Budgets

```ts
budget: { js: '320 kB', css: '60 kB' },
```

The build fails when the JavaScript or CSS every page loads first is larger,
gzipped. Code loaded later, like diagrams, does not count. `novon build`
prints both sizes; `--budget-js` and `--budget-css` override the config.

## Search engines

Each page carries structured data: the site, the page as a technical article
(docs) or a blog post (dated pages in a blog layout), and its breadcrumbs.
`head` adds tags to every page; frontmatter `head` and `noindex` work per page.

## Checking

`novon build` validates the config, frontmatter, links and redirects, and
prints what it finds. See [Checking](/guide/checking).

## Plugins

Built-in plugins are named by string; your own are objects with hooks. See
[Plugins](/guide/plugins).
