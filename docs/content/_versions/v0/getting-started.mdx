novon runs on [Bun](https://bun.sh) 1.2 or newer.

<Steps>
  <Step title="Install">
    ```bash
    bun add -g novon@latest
    ```
  </Step>
  <Step title="Create a site">
    ```bash
    novon new my-docs                  # docs layout
    novon new my-blog --template blog  # blog layout
    novon new --yes                    # in the current folder, no questions
    ```
    In a folder that already has files (a repository with a README), `novon new`
    adds the template's files beside them and leaves yours alone. Every new site
    gets an `AGENTS.md` that tells coding agents how to work on it.
  </Step>
  <Step title="Preview">
    ```bash
    cd my-docs
    novon dev
    ```
    Pages reload as you save. New files show up in the sidebar.
  </Step>
  <Step title="Build">
    ```bash
    novon build    # writes dist/
    novon preview  # serves dist/ locally
    ```
  </Step>
</Steps>

## What a site looks like

```text
my-docs/
├── novon.config.ts
├── content/
│   ├── index.mdx            → /
│   ├── getting-started.mdx  → /getting-started
│   └── guide/
│       ├── index.mdx        → /guide
│       └── writing.mdx      → /guide/writing
└── public/                  copied to the output root
```

Folders under `content/` become sidebar sections. A folder's `index.mdx` names
the section, and its label links to that page.
