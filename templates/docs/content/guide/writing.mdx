## Tabs

Use tabs when readers pick one path, like an operating system.

<Tabs>
  <Tab title="macOS">Settings are in `~/Library/Application Support`.</Tab>
  <Tab title="Linux">Settings are in `~/.config`.</Tab>
  <Tab title="Windows">Settings are in `%APPDATA%`.</Tab>
</Tabs>

## Code

Fences are highlighted at build time. `title` adds a caption.

```ts title="src/greet.ts"
export function greet(name: string) {
  return `Hello, ${name}`
}
```

Several fences in a `CodeGroup` become tabs:

<CodeGroup>

```ts title="greet.ts"
greet('world')
```

```py title="greet.py"
greet("world")
```

</CodeGroup>
