title: Getting started
description: Write a page and see it live.
icon: Bolt
order: 1
---

<Steps>
  <Step title="Start the preview">
    ```bash
    novon dev
    ```
  </Step>
  <Step title="Add a page">
    Create `content/guide/hello.mdx`. It appears in the sidebar right away.
  </Step>
  <Step title="Build">
    ```bash
    novon build
    ```
    The static site is in `dist/`.
  </Step>
</Steps>
